If you learned generics when they first arrived, this session will help you catch up on what’s changed, what’s now possible, and which patterns are finally ready for production use.

Finally, we will build a machine learning algorithm that responds to the metrics to optimize the worker pool settings during processing. For this we’ll use a set of evolutionary algorithms that respond to health signals from the worker pool’s exposed metrics.
